
# Các dịch vụ AWS sử dụng

## 1. Amazon S3
Lưu trữ các file CV PDF được ứng viên tải lên.

## 2. Amazon Textract
Trích xuất nội dung văn bản từ CV PDF để phục vụ quá trình phân tích.

## 3. AWS Lambda
Thực hiện xử lý nội dung CV, nhận diện kỹ năng, kinh nghiệm và tính điểm phù hợp.

## 4. Amazon DynamoDB
Lưu trữ thông tin công việc, ứng viên và kết quả đánh giá CV.

## 5. Amazon API Gateway
Cung cấp API để các thành phần ứng dụng giao tiếp với hệ thống backend.

## 6. Amazon CloudWatch
Theo dõi nhật ký hoạt động, hỗ trợ kiểm tra và phát hiện lỗi.

## 7. AWS Step Functions
Dự kiến sử dụng để điều phối các bước trong quy trình xử lý CV.
